# 打造自己的呆萌型 AI 機器人（最終版構想）

## 1. 對 AI 機器人有什麼期望？

我想做一個能看商品圖片，幫我選擇記帳類別的 AI。平常買完東西記帳時，除了輸入金額，還要自己選類別。我希望能上傳商品照片，讓它先判斷，再由我確認，減少手動分類的步驟。

這次先從原本「記帳與消費建議 AI」的構想中，挑出商品分類這一個功能。它需要透過大量有分類標籤的圖片，學習不同商品的外觀特徵。

使用時，每張圖片只放一件主要商品，例如鍵盤、衣服或飲料。如果買了好幾種東西，就分開提供圖片。

## 2. 它的輸入是什麼？

每次輸入固定為一張商品圖片。圖片會先保持比例縮放，不足的地方補白邊，統一處理成 128 × 128 像素的彩色圖片。

每個像素包含紅、綠、藍三個數值，各自介於 0～255，因此每次實際送進模型的輸入固定為：
128 × 128 × 3＝49,152 個數值。

使用者只需要上傳圖片，不用自己填這些數字，尺寸調整和像素轉換由程式處理。

例如，我買了一個鍵盤，就上傳只包含該鍵盤的商品照片，讓模型判斷它屬於哪一類。這次不要求模型讀取商品名稱或價格。

## 3. 它的輸出是什麼？

輸出固定為六個介於 0～1 的機率數值，總和為 1，順序如下：

1. 食品飲料
2. 服飾配件
3. 電子產品
4. 文具
5. 居家用品
6. 其他

例如，輸入鍵盤圖片後，可能得到：
`[0.01, 0.01, 0.94, 0.02, 0.01, 0.01]`

這是輸出格式的示意。第三個位置的數值最高，所以畫面會顯示建議類別為「電子產品」。

我可以確認或修改分類，再由記帳程式保存。模型本身只輸出這六個數值，不產生購買建議，也不負責計算剩餘預算。

## 4. 打算使用什麼數據？

我打算取得店家或商品資料提供者的授權，收集商品圖片與原有分類，再搭配多人自行拍攝、同意提供的商品照片，讓資料包含不同背景、光線和拍攝角度。

預計每類收集約 5,000 張圖片，六類合計約 30,000 張。

收集後，會依照同一套分類規則整理標籤，例如鍵盤屬於電子產品、筆記本屬於文具、杯子屬於居家用品。不屬於前五類的商品歸入其他類；這一類也要收集不同商品，不能只用一種物品代表。分類有爭議的圖片會先確認，無法確定的就暫時排除。

每筆訓練資料包含一張固定尺寸的圖片，以及六個位置的分類標籤。正確類別填 1，其餘填 0。例如：
* 鍵盤圖片 → `[0, 0, 1, 0, 0, 0]`
* 飲料圖片 → `[1, 0, 0, 0, 0, 0]`

整理資料時會排除重複、過度模糊，或同時出現多種主要商品的圖片。訓練與測試資料會按照商品分開，同一件商品的不同角度照片放在同一組，避免模型只是記住曾經看過的商品。

最後用未參與訓練的商品圖片測試，觀察分類正確率，以及哪些類別比較容易被搞混。

## 原始構想與這次的調整

原本我想做的是「記帳與消費建議 AI 機器人」，重新看過作業要求後，發現包含的功能太多，所以這次先挑出商品分類的部分。輸入固定尺寸的商品圖片，輸出六種類別的機率，協助使用者選擇記帳類別。
